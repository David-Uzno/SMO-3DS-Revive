# Super Mario Odyssey for Nintendo 3DS - Demake
[Versión en Español](README.md)

This project is a faithful adaptation of *Super Mario Odyssey* for the Nintendo Switch for the **Nintendo 3DS** console, developed with **Unity**.

The main goal of this project is to recreate the original *Super Mario Odyssey* experience with as few modifications as possible, maintaining the core gameplay mechanics, levels, and features. However, minimal adjustments have been made to ensure performance and playability on the Nintendo 3DS platform.

> ⚠️ This is an unofficial, non-profit project. Super Mario Odyssey, its characters, music, art, levels, and all other related content are the intellectual property of Nintendo Co., Ltd.

## Technologies Used
- **Development Engine:** [Unity](https://unity.com/) (5.6.6f2)
- **Programming Language:** C#
- **Target Platform:** Nintendo 3DS
