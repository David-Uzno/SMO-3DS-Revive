# *Super Mario Odyssey™* for *Nintendo 3DS™* - Demake (English 🇺🇸)

This project is a faithful adaptation of Nintendo Switch's *Super Mario Odyssey™* for the **Nintendo 3DS™** console, developed with **Unity**.

The main objective is to recreate the original *Super Mario Odyssey™* experience with as few modifications as possible, maintaining the gameplay mechanics, levels/worlds, and core features. However, minimal adjustments have been made to ensure performance and playability on the *Nintendo 3DS™* platform.

> ⚠️ This is an unofficial, non-profit project. *Super Mario Odyssey™*, its characters, music, art, levels, and any other related content are the intellectual property of **Nintendo Co., Ltd.**

## Technologies Used

- **Development Engine:** [Unity](https://unity.com/)
- **Programming Language:** C#
- **Target Platform:** *Nintendo 3DS™*
