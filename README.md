# Super Mario Odyssey™ para Nintendo 3DS™ – Demake  
**Versión: Alpha 0.5 (a0.5)**  
(Español 🇲🇽)

Este proyecto es una adaptación fiel de *Super Mario Odyssey™* de *Nintendo Switch™* para la consola **Nintendo 3DS™**, desarrollado con **Unity**.

El objetivo principal es recrear la experiencia original de *Super Mario Odyssey™* con la menor cantidad de modificaciones posibles, manteniendo las mecánicas de juego, niveles y características principales. Sin embargo, se han realizado ajustes mínimos necesarios para garantizar el rendimiento y la jugabilidad en la plataforma Nintendo 3DS™.

> ⚠️ Este es un proyecto no oficial y sin fines de lucro. *Super Mario Odyssey™*, sus personajes, música, arte, niveles y cualquier otro contenido relacionado son propiedad intelectual de **Nintendo Co., Ltd.**

---

## Tecnologías Utilizadas

- **Motor de Desarrollo:** [Unity](https://unity.com/)
- **Lenguaje de Programación:** C#
- **Plataforma Objetivo:** Nintendo 3DS™

---

## Roadmap  
**Alpha 0.5 → 0.6** — Completado [❌]

### Etapa 1 – Limpieza y Reorganización [❌]
🎯 **Objetivo:** Tener una base estable, limpia y documentada para comenzar la integración de nuevas mecánicas.

**Tareas:**
- Reorganizar la estructura de carpetas (Assets/, Objects/, Scripts/, etc.). [❌]
- Renombrar archivos y escenas con nombres descriptivos. [❌]
- Normalizar nombres de clases, métodos y variables (camelCase / PascalCase). [❌]
- Eliminar código redundante, comentado o sin uso. [❌]
- Separar responsabilidades. [❌]
- Crear documentación básica. [❌]
- Actualizar el README. [✅]

### Etapa 2 – Coleccionables [❌]
🎯 **Objetivo:** Implementar los elementos básicos de recolección del juego.

**Tareas:**
- Pila de monedas. [❌]
- Monedas invisibles. [❌]

### Etapa 3 – Interactividad y Ambientación [❌]
🎯 **Objetivo:** Introducir elementos para hacer el entorno más responsivo.

**Tareas:**
- Arbustos. [❌]
- Faroles. [❌]
- Flores. [❌]
- Posters. [❌]
- Vallas. [❌]
- Corazones de vida. [❌]

### Etapa 4 – Sistemas Fundamentales [❌]
🎯 **Objetivo:** Implementar los sistemas principales que sostendrán las futuras actualizaciones.

**Tareas:**
- Integración y configuración de RID-Tools. [❌]
- HUD básico (monedas actualizables, brújula y salud estáticas). [❌]
- Menú de pausa (forma básica). [❌]

### Etapa 5 – Pulido [❌]
🎯 **Objetivo:** Garantizar que todos los sistemas convivan sin errores graves y dejar lista una versión jugable.

**Tareas:**
- Corrección de errores y bugs críticos. [❌]
- Optimización básica de rendimiento. [❌]
- Documentación final. [❌]
- Generación de build Alpha 0.6. [❌]

📌 **Resultado:** Versión Alpha 0.6 funcional, estable y con primeras incorporaciones de interactividad y ambientación, lista para futuras expansiones de contenido.

# *Super Mario Odyssey™* for *Nintendo 3DS™* – Demake

- Basic pause menu. [❌]

### Stage 5 – Polish [❌]
🎯 **Objective:** Ensure all systems coexist without major errors and prepare a playable build.

**Tasks:**
